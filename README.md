# 🌷 Good Pastel — Music Diary 🎧✨

> *A little corner of my world, filled with songs, soft colors, and happy little moments.* 🩵

Selamat datang di **Music Diary**, sudut kecil dari Good Pastel yang dibuat untuk merayakan hal-hal sederhana yang membuat hari terasa lebih berwarna: musik favorit, kenangan, dan artis yang punya tempat spesial di hati. 🌈☁️

Di sini, warna pastel bertemu dengan playlist yang menemani hari-hari — terutama lagu-lagu dari **INFINITE** dan **GOT7**. Semoga halaman ini terasa seperti membuka jendela kecil ke dunia musikku. 💿💗

## 🫧 Tentang Music Diary

Music Diary adalah halaman personal yang melengkapi Good Pastel. Jika bagian portfolio menampilkan karya dan perjalanan belajar, halaman ini memberi ruang untuk sisi yang lebih santai: musik yang didengarkan berulang kali, grup favorit, dan sedikit cerita di baliknya.

Yang ada di halaman ini:

- 🎶 **Yol's Playlist** — playlist YouTube untuk menemani hari.
- 💙 **INFINITE** — grup yang menjadi salah satu bagian istimewa dari selera musikku.
- 💚 **GOT7** — lagu-lagu yang ikut mengisi playlist sehari-hari.
- 💌 **A Special Little Corner** — ruang apresiasi untuk L · Kim Myung-soo.

## 💿 Yol's Playlist

Bagian playlist menggunakan foto grup INFINITE sebagai **cover khusus** dengan judul **Yol's Playlist**.

Cara kerjanya:

1. Pengunjung melihat cover foto INFINITE.
2. Saat cover atau tombol play ditekan, pemutar YouTube playlist dimuat.
3. Pengunjung juga dapat memilih tautan **Open playlist on YouTube** untuk membuka playlist secara langsung.

Playlist YouTube yang digunakan:

[🎧 Buka Yol's Playlist di YouTube](https://youtube.com/playlist?list=PLY2KXk4Vugn9qO6OErDhCBJsnYZ7Muyss)

## 📁 Struktur File

Pastikan file dan folder berikut berada pada lokasi yang sesuai di repository GitHub Pages:

```text
repository/
├── index.html
├── style.css
├── script.js
├── music-diary.html
├── music-diary.css
├── README.md
├── img/
│   ├── photo1.png
│   └── yol-playlist-infinite.jpeg
└── fonts/
    ├── halimun-webfont.woff
    └── halimun-webfont.woff2
```

File `photo1.png` dan folder `fonts/` merupakan aset website utama jika masih digunakan. Pertahankan aset lama yang dibutuhkan oleh halaman lain.

## 🚀 Memasang di GitHub Pages

1. Unduh dan ekstrak paket website yang sudah diperbarui.
2. Buat cadangan file yang saat ini ada di repository.
3. Unggah atau ganti file yang telah direvisi sesuai struktur folder di atas.
4. Pastikan foto playlist berada di `img/yol-playlist-infinite.jpeg`.
5. Commit perubahan dan push ke branch yang digunakan oleh GitHub Pages.
6. Tunggu proses deployment selesai, lalu buka website dan coba klik cover playlist.

Jika gambar tidak muncul, periksa kembali nama file, huruf besar/kecil, dan jalur relatif pada HTML. Nama file di GitHub Pages harus cocok persis dengan yang dipanggil kode.

## 🪄 Mengganti Playlist atau Foto

### Mengganti playlist YouTube

Buka `music-diary.html`, lalu cari URL playlist pada bagian kode pemutar dan tautan YouTube. Ganti ID playlist dengan ID playlist milikmu yang baru. Pastikan kedua tautan mengarah ke playlist yang sama.

### Mengganti foto cover

1. Siapkan foto yang ingin digunakan.
2. Letakkan foto di folder `img/`.
3. Ubah jalur gambar pada `music-diary.html` agar menunjuk ke nama file yang baru.
4. Simpan perubahan, commit, dan periksa kembali website.

Gunakan foto yang kamu miliki atau yang penggunaannya memang diizinkan. Jika foto berasal dari pihak lain, ikuti ketentuan kredit dan lisensinya.
